# VLAN Segmentation and Network Topology

## Project Overview

This academic networking project explores network segmentation and IP addressing using Cisco Packet Tracer. The simulated network includes separate logical networks for employee workstations, guest wireless devices, and video surveillance equipment.

The project demonstrates foundational networking concepts relevant to IT support, network administration, and cybersecurity.

## Technologies Used

- Cisco Packet Tracer
- Virtual LANs (VLANs)
- IPv4 Addressing
- Ethernet Switching
- Wireless Networking
- Network Topology Design

## Network Architecture

The topology includes the following network segments:

| VLAN | Purpose | Devices |
|---|---|---|
| 50 | Employee Workstations | Two computers |
| 70 | Guest Wireless Network | Smartphone and tablet |
| 80 | Video Surveillance | Two cameras |

The design illustrates how different device categories can be organized into separate logical network segments.

## Project Activities

- Developed a simulated network topology using Cisco Packet Tracer.
- Organized employee, guest, and surveillance devices into designated network segments.
- Documented IPv4 addressing for devices within the simulated environment.
- Examined the role of network segmentation in organizing and securing network infrastructure.
